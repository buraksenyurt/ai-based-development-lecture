# IK Portalinin Geliştirilmesi

Klasik yaklaşımdan ziyade YZ destekl' yaklaşımla ilerlemeye çalıştığımız düşünelim. Yöntemlerden birisi sistem promptlarını hazırlamadan önce spec dokümanları hazırlamaktır. Bu dokümanlarda teknik detaylar verilir. Domain kurgusu, uygulanması istenen mimari kurallar, yazılım prensipleri, teknoloji altyapısı gibi.

İyi sonuçlar elde edebilmek için büyük bir projeyi küçük parçalar halinde ele almak gerekebilir. Her bir parçaya çeşitli sorular sorulur ve cevaplar spec dokümanlarının oluşturulmasında kullanılır. Örneğin projenin amacı nedir, hangi programlama dili kullanılacaktır, veri nerede tutulacaktır gibi soruların cevapları bu dokümanların hazırlanmasında kullanılabilir.

Örneğin;

## Proje Amacı

İşe başvuru yapacak adayların bilgilerini gösteren, belirli kriterlerde sorgulama yapmamızı sağlayan, web tabanlı bir uygulama yazmak istiyoruz.
